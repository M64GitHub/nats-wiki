# gh#5606 — Manage streams / KVs across multiplea accounts with one user

Category: Q&A · opened 2024-06-28 by @pcsegal · answer chosen: 2024-08-10

## Original post

When NATS is configured with multiple accounts, I can have one user for each account and, if I need to manage streams / KVs in an account, I need to authenticate as the user of the respective account.
However, it looks like I can't have a single user that can manage streams/KVs in multiple accounts.
I have a scenario where I would like to manage streams in multiple accounts. Is there a way of doing that without having to separately connect as each user's account?

## Comment — @Jarema (2024-07-01)

Each account is a separate tenant, with fully isolated subject context etc.
You cannot use one user to manage multiple streams.
Even if you want to share some data between accounts, you need to explicitly specify imports/exports.

You can however use system account to overview the whole NATS & JetStream system.

### Reply — @derekcollison (2024-08-10)

The system account provides JetStream as a service to all enabled accounts. So that is correct, you can not enable JetStream on the system account.

## Comment — @atlejensen (2024-07-05)

It depends on your usecase, but there are some options outside NATS.
Synadia Control Plane builds on top of your NATS environment(s) and gives you an overlay where you can manage multiple accounts with a single user. check out https://docs.synadia.com/platform/control-plane
There is also Qaze, a desktop tool that may solve some of your challenges. check out https://qaze.app/
