# gh#2855 — Could I publish message with wildcards

## Original post

Could I use some wildcards to broadcast message?

`publish_topic: "abc.*.cd.>" ?`

Thanks.

## Comment — @derekcollison (2022-02-09) · **chosen answer**

You can only send to literal subjects when publishing. Wildcards are only applicable for subscriptions.
