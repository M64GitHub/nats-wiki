### Reply — @Material-Scientist (2024-10-31)

So, the (experimental) Kafka tiered storage class (`org.apache.kafka.server.log.remote.storage.LocalTieredStorage`) just uses a local directory to [move segments once they are rolled](https://kafka.apache.org/documentation/#tiered_storage_config_ex).

In my case, that directory is a mounted [SeaweedFS ](https://github.com/seaweedfs/seaweedfs) drive (append-only store), which first stores the data on a fast drive (e.g. SSD), and eventually moves it to slower tiers (e.g. HDD, S3).

Both Kafka & SeaweedFS cache the data back to the local drive as soon as a consumer requires old segments.

Since storage is often the most expensive part about operating Kafka, it's important to have support for tiered storage.

It would be great if NATS supported tiered storage in a similar fashion (i.e. sealed segments are moved to a different directory, and cached when needed).
