# gh#7672 — Cron schedule supports ?

Category: Q&A · opened 2025-12-21 by @evmd · answer chosen: 2025-12-21

## Original post

As specified in[ ADR-51](https://github.com/nats-io/nats-architecture-and-design/blob/main/adr/ADR-51.md) and #6884
Cron-like schedules should work, but seems the server returns `message schedules pattern is invalid` when sending any cron formatted schedule specification.

Is it supported ? Can't find much more info in the docs or code.

## Comment — @MauriceVanVeen (2025-12-21) [marked as answer]

Only single scheduled messages from that ADR were released as part of 2.12, see also: https://nats.io/blog/nats-server-2.12-release/#delayed-message-scheduling

The remaining items, like cron-like schedules, will be part of version 2.14 to be released March of next year.
