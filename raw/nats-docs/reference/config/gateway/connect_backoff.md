# connect\_backoff

Available since NATS Server `2.12`

Requires Restart

Back off between gateway reconnect attempts instead of retrying at a fixed interval.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
