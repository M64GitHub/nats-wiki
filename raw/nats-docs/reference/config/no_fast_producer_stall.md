# no\_fast\_producer\_stall

Hot Reloadable

Do not stall a fast producer when a consumer cannot keep up. The server drops messages to the slow consumer instead.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
