# feature\_flags

Available since NATS Server `2.14`

Requires Restart

Toggles for features that are not yet on by default. Names are server-internal and change between releases.

## Types

| Type                  | Description | Choices         |
| --------------------- | ----------- | --------------- |
| `{ string: boolean }` | -           | `true`, `false` |
