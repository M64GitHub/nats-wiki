# nkey

Hot Reloadable

Public NKey identifying the user. The value begins with a `U` character. Exclusive with `username` and `password`.

## Types

| Type     | Description | Choices |
| -------- | ----------- | ------- |
| `string` | -           | -       |

## Examples

```
UDXU4RCSJNZOIQHZNWXHXORDPRTGNJAHAHFRGZNEEJCPQTT2M7NLCNF4
```
