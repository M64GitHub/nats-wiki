# proxy\_required

Available since NATS Server `2.12`

Requires Restart

Reject client connections that did not arrive through a PROXY protocol header.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
