# ping\_interval

Available since NATS Server `2.12`

Requires Restart

How often the server sends a WebSocket ping. Set `0` to disable.

## Types

| Type       | Description                                                    | Choices |
| ---------- | -------------------------------------------------------------- | ------- |
| `duration` | Duration as a string with units such as 100ms, 10s, 5m, or 2h. | -       |
