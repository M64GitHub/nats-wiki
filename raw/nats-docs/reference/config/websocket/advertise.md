# advertise

Requires Restart

Advertised client `<host>:<port>`. Useful for cluster setups behind a NAT.

## Types

| Type     | Description                                                       | Choices |
| -------- | ----------------------------------------------------------------- | ------- |
| `string` | This is an alternate to setting the `host` and `port` separately. | -       |
