# compress

Aliases:

<!-- -->

`compression`

Requires Restart

This enables support for compressed websocket frames in the server. For compression to be used, both server and client have to support it.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
