# verify

Ignored Until Restart

Reload succeeds and the value is stored, but ClientAuth is ignored on an outbound client connection, so nothing changes.

If true, require and verify client certificates. Does not apply to monitoring.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
