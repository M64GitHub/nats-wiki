# max\_buffered\_size

Requires Restart

Byte ceiling for that same buffer.

## Types

| Type      | Description                                                              | Choices |
| --------- | ------------------------------------------------------------------------ | ------- |
| `storage` | Size in bytes or string with a metric unit such as 100K, 50M, 3G, or 1T. | -       |
