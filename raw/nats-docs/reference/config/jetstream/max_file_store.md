# max\_file\_store

Aliases:

<!-- -->

`max_file`

Hot Reloadable

2.12/2.14: increases only. 2.11: never, while enabled.

Maximum size of the *file* storage. Defaults to up to 1TB if available.

## Types

| Type      | Description                                                              | Choices |
| --------- | ------------------------------------------------------------------------ | ------- |
| `storage` | Size in bytes or string with a metric unit such as 100K, 50M, 3G, or 1T. | -       |
