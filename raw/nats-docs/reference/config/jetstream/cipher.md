# cipher

Requires Restart

Defines the encryption algorithm to use if an encryption key is defined.

## Types

| Type     | Description | Choices                       |
| -------- | ----------- | ----------------------------- |
| `string` | -           | `chacha`, `chachapoly`, `aes` |
