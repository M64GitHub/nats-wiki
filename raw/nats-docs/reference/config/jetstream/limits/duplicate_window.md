# duplicate\_window

Requires Restart

The maximum duplication window period allowed to be configured on a stream.

## Types

| Type       | Description                                                    | Choices |
| ---------- | -------------------------------------------------------------- | ------- |
| `duration` | Duration as a string with units such as 100ms, 10s, 5m, or 2h. | -       |
