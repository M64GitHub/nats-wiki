# meta\_compact\_size

Available since NATS Server `2.12`

Hot Reloadable

Metalayer Raft log size that triggers compaction.

## Types

| Type      | Description                                                              | Choices |
| --------- | ------------------------------------------------------------------------ | ------- |
| `storage` | Size in bytes or string with a metric unit such as 100K, 50M, 3G, or 1T. | -       |
