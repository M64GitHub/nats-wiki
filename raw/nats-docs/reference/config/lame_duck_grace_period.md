# lame\_duck\_grace\_period

Requires Restart

This is the duration the server waits, after entering lame duck mode, before starting to close client connections

## Types

| Type       | Description                                                    | Choices |
| ---------- | -------------------------------------------------------------- | ------- |
| `duration` | Duration as a string with units such as 100ms, 10s, 5m, or 2h. | -       |
