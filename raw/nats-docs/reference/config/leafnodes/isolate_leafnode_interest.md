# isolate\_leafnode\_interest

Aliases:

<!-- -->

`isolate`

Available since NATS Server `2.12`

Requires Restart

Do not propagate subscription interest learned from one leaf node to the others attached to this server.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
