# insecure

Hot Reloadable

On 2.11/2.12 the reload succeeds but nothing changes.

Skip certificate verification. This only applies to outgoing connections, NOT incoming client connections. **not recommended.**

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
