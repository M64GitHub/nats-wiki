# cipher\_suites

Hot Reloadable

On 2.11/2.12 the reload succeeds but nothing changes.

When set, only the specified TLS cipher suites will be allowed. Values must match the golang version used to build the server.

| Type     | Description | Choices |
| -------- | ----------- | ------- |
| `string` | -           | -       |
