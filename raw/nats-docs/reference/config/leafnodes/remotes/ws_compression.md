# ws\_compression

Aliases:

<!-- -->

`ws_compress`, `websocket_compress`, `websocket_compression`

Requires Restart

If true, and connecting with the WebSocket protocol, the connection will indicate to the remote that it wishes compression to be used.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
