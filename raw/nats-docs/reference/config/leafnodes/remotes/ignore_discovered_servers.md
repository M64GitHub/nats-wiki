# ignore\_discovered\_servers

Available since NATS Server `2.14`

Requires Restart

Connect only to the URLs listed here, ignoring any additional servers the remote advertises.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
