# request\_isolation

Available since NATS Server `2.12`

Requires Restart

Ask the remote to isolate this connection's interest on its side.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
