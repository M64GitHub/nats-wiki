# first\_info\_timeout

Requires Restart

How long to wait for the remote's `INFO` message before giving up on the connection.

## Types

| Type       | Description                                                    | Choices |
| ---------- | -------------------------------------------------------------- | ------- |
| `duration` | Duration as a string with units such as 100ms, 10s, 5m, or 2h. | -       |
