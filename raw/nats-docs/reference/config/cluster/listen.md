# listen

Requires Restart

Only a listen string whose host is unchanged AND whose port is `-1` survives reload.

## Types

| Type     | Description                                                       | Choices |
| -------- | ----------------------------------------------------------------- | ------- |
| `string` | This is an alternate to setting the `host` and `port` separately. | -       |
