# allow\_insecure\_cipher\_suites

Available since NATS Server `2.12`

Hot Reloadable

Permit cipher suites Go considers insecure to be named in `cipher_suites`. Without it those names are rejected.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
