# trace

Hot Reloadable

Ignored if `-V`, `-VV`, `-DV` or `-DVV` was passed at startup — command-line boolean flags are re-applied over the config on every reload.

If true, enables protocol trace log messages, excluding the system account.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
