# disable\_sublist\_cache

Aliases:

<!-- -->

`no_sublist_cache`

Requires Restart

If true, disable subscription caches for all accounts. This saves resources in situations where different subjects are used all the time.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
