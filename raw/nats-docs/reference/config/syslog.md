# syslog

Hot Reloadable

Ignored if `-s` or `-syslog` was passed at startup — command-line boolean flags are re-applied over the config on every reload.

Log to syslog.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
