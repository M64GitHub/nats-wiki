# websocket

Aliases:

<!-- -->

`ws`

Hot Reloadable

Only the TLS certificate material reloads, and only for connections accepted afterwards. Every other `websocket` setting fails the reload, including `verify_and_map` and `pinned_certs`.

Configuration for enabling the WebSocket interface.
