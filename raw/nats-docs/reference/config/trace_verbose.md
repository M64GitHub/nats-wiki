# trace\_verbose

Hot Reloadable

Also enables `trace`. Ignored if `-VV` or `-DVV` was passed at startup.

If true, enables protocol trace log messages, including the system account.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
