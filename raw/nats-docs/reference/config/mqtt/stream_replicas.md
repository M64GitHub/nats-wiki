# stream\_replicas

Hot Reloadable

Takes effect only for MQTT streams that have not been created yet.

If specified, sets an explicit number of stream replicas to be used for MQTT-backed streams.

## Types

| Type      | Description | Choices |
| --------- | ----------- | ------- |
| `integer` | -           | -       |
