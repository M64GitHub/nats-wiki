# reject\_qos2\_publish

Requires Restart

Reject QoS 2 publishes instead of accepting them, for clients that must not silently get weaker delivery guarantees.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
