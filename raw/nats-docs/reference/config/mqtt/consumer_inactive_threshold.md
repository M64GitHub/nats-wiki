# consumer\_inactive\_threshold

Aliases:

<!-- -->

`consumer_auto_cleanup`

Hot Reloadable

Existing consumers are not modified.

Set an explicit default inactive threshold for consumers used by MQTT.

## Types

| Type       | Description                                                    | Choices |
| ---------- | -------------------------------------------------------------- | ------- |
| `duration` | Duration as a string with units such as 100ms, 10s, 5m, or 2h. | -       |
