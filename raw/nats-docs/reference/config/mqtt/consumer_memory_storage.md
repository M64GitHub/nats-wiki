# consumer\_memory\_storage

Hot Reloadable

Existing consumers are not modified.

Hold MQTT consumer state in memory rather than on disk.

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
