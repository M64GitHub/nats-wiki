# debug

Hot Reloadable

Ignored if `-D`, `-DV` or `-DVV` was passed at startup — command-line boolean flags are re-applied over the config on every reload.

If true, enables debug log messages.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
