# verify\_and\_map

Requires Restart

If true, require and verify client certificates and map certificate values for authentication. Does not apply to monitoring.

## Types

| Type      | Description | Choices         |
| --------- | ----------- | --------------- |
| `boolean` | -           | `true`, `false` |
